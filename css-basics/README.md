폴더 하나 = 개념 하나 🍡 각 폴더는 아주 작은 예제 + 진한 주석으로 구성되어 있어서,
나중에 다시 열어봐도 "아 이게 이런 거였지" 하고 바로 이해할 수 있게 만듭니다.

## 🐾 진행 방법

1. 폴더 순서대로 진행 (밑에 있을수록 어려움)
2. `index.html`과 `style.css`를 Live Server로 열어서 먼저 결과를 본다
3. 주석을 하나씩 읽으면서 값을 이것저것 바꿔본다 (숫자, 색 등)
4. 다 이해됐으면 커밋 ✅ `git commit -m "css-basics 01 완료: 선택자"`

## 🗺️ 로드맵

- [x] 01. 선택자(Selector) — 태그/클래스/아이디 선택자, 하위 선택자, 여러 개 묶어 선택하기
- [ ] 02. 박스 모델(Box Model) — width/height, padding, border, margin, box-sizing
- [ ] 03. 색상과 단위(Color & Unit) — hex/rgb/rgba, px/%/em/rem/vw/vh
- [ ] 04. 글자(Typography) — font-family, font-size, font-weight, line-height, text-align
- [ ] 05. display와 position — block/inline/inline-block, static/relative/absolute/fixed
- [ ] 06. Flexbox — 컨테이너 속성, 아이템 속성 (가로/세로 정렬의 핵심)
- [ ] 07. Grid — 격자 레이아웃 기초
- [ ] 08. 가상 클래스(Pseudo-class) — :hover, :nth-child, :first-child, :last-child
- [ ] 09. transition & animation — 부드러운 변화, 애니메이션 기초
- [ ] 10. 반응형(Media Query) — 화면 크기에 따라 스타일 바꾸기

## 💭 스타일 규칙

- 모든 CSS 속성 옆에는 "이게 왜 필요한지 / 뭘 하는지" 한글 주석을 남긴다 📝
- 예제는 최대한 작게 (눈으로 바로 효과가 보이는 정도)
- 헷갈렸던 부분은 파일 맨 아래 `# 헷갈렸던 점` 섹션에 직접 메모해두면 나중에 진짜 도움됨 🐱
