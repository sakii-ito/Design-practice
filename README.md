# ui-ux-practice

HTML/CSS/JS 기초 + UI/UX 감각을 조금씩 쌓아가는 연습용 리포지토리입니다.
한 챕터 = 폴더 하나. 각 폴더는 미션 설명(`README.md`) + 시작용 코드(TODO 포함) + `solution` 폴더로 구성됩니다.

## 진행 방법

1. 챕터 폴더의 `README.md`를 읽는다
2. `index.html` / `style.css`의 TODO를 채운다
3. Live Server로 확인
4. 막히면 `solution` 폴더 확인
5. 완료했으면 커밋 (`git add . && git commit -m "01 완료: 자기소개 카드"`)

## 로드맵

- [ ] 01. 자기소개 카드 — HTML 기본 태그, Flexbox 가운데 정렬, 카드 스타일
- [ ] 02. 버튼 갤러리 — flex-wrap, hover, transition, nth-child
- [ ] 03. 좋아요 카운터 — JS 기초, 이벤트, DOM 조작
- [ ] 04. 숫자 맞추기 게임 — 조건문, 입력값 처리
- [ ] 05. 할 일 목록(To-do List) — 배열, 동적 추가/삭제
- [ ] 06. 데이터 카드 갤러리 — 배열 데이터를 카드로 렌더링
- [ ] 07. (추가 예정)

## 기술 스택

HTML / CSS / JavaScript (바닐라, 프레임워크 없이 기본기부터)

## 참고

각 챕터는 독립적으로 실행 가능합니다. 폴더 안 `index.html`을 Live Server로 열면 됩니다.
