# Design practice

HTML/CSS 기초 코딩 감각과 UI/UX 디자인 감각을 함께 쌓아가는 연습용 리포지토리입니다.
두 갈래로 나눠서 진행합니다:

## 구성

- **`css-basics/`** — CSS를 개념별로 하나씩 파고드는 코딩 연습
  (선택자, 박스 모델, 색상/단위, 타이포그래피, flexbox, grid 등)
- **`ui-ux-study/`** — 타비도리 프로젝트 담당분(전체 UI/UX 디자인, 마이페이지·관리자 화면)에
  맞춘 디자인 학습. 이론(note.md) + 실습(실습.md)으로 구성, 배운 걸 바로 프로젝트에 적용.

각 폴더 안의 README.md(또는 note.md)에 더 자세한 로드맵이 있습니다.

## 진행 방법

1. 각 트랙의 README/note를 읽는다
2. 작은 예제나 실습 과제를 직접 해본다
3. 완료했으면 커밋: `git add . && git commit -m "메시지" && git push`

## 기술 스택

HTML / CSS / JavaScript (바닐라) + Figma(디자인)
