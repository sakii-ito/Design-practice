# 실습: 타비도리 디자인 시스템 v0 만들기

note.md에서 배운 3가지(색상/타이포/여백)를 실제로 타비도리에 적용해서 정해봅니다.
완벽하지 않아도 됩니다 — 팀 회의에서 보여주고 의견 받아서 나중에 고치면 됩니다.
일단 "기준선"을 하나 만드는 게 목적입니다.

## 과제 1: 색상 팔레트 정하기

Figma(또는 아무 메모장)에 아래 항목을 채워보세요.

- [ ] Primary 색 1개 (타비도리 = 여행 기록 앱. 어떤 느낌의 색이 어울릴지 생각해보기)
- [ ] Neutral 색 5단계 (흰색 → 연회색 → 회색 → 진회색 → 검정에 가까운 색)
- [ ] Semantic 색 3개
  - [ ] 성공/통과 (검증 결과 통과, 일정 확정 등에 사용)
  - [ ] 실패/에러 (검증 결과 실패, 병목 하이라이트에 사용)
  - [ ] 경고/애매함 (채팅 응답 처리 코드의 "애매한 취향 요청" 같은 경우)

> 힌트: 색 코드가 안 떠오르면 "color palette generator" 검색해서 나온 도구에
> Primary 색 하나만 넣으면 어울리는 나머지 색을 자동으로 제안해줍니다.

## 과제 2: 타이포그래피 스케일 정하기

note.md의 표를 그대로 써도 되고, 숫자만 타비도리에 맞게 조정해도 됩니다.

- [ ] Heading 1 (페이지 제목용) 크기 정하기
- [ ] Heading 2 (섹션 제목용) 크기 정하기
- [ ] Body(본문) 크기 정하기
- [ ] 폰트 굵기 2~3단계만 정하기

## 과제 3: 여백 규칙 정하기

- [ ] 4의 배수 중 실제로 쓸 값 5~6개 고르기 (예: 4, 8, 16, 24, 32px)

## 과제 4: 한 장으로 정리

위 1~3번 결과를 Figma 프레임 하나에 모아서 "타비도리 디자인 시스템 v0"라는
이름으로 저장해두세요. 이게 앞으로 마이페이지/관리자 화면, 그리고 다른 화면
목업 만들 때마다 계속 참고하게 될 기준표입니다.
