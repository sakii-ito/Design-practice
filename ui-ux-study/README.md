타비도리 프로젝트에서 사키 담당분(전체 UI/UX 디자인, 마이페이지·관리자 화면)을
실제로 해낼 수 있게 만드는 것이 목표인 학습 폴더입니다 🐾
이론만 넓게 배우는 게 아니라, "이걸 배우면 바로 프로젝트에 쓴다"는 순서로 짰습니다.

## 💡 왜 이 순서인가

담당표를 보면 사키님 산출물은 "디자인 시스템 + 화면별 목업 / 전체 화면 일관된 스타일"과
"마이페이지·관리자 화면"입니다. 즉:
1. 먼저 디자인 시스템(색/글자/여백의 규칙)을 정해야
2. 그 규칙으로 화면들을 목업할 수 있고
3. 그 결과물이 전체 화면(스팟검색, 일정편집, 채팅 등)에 다 같이 적용돼서 "일관성"이 생김

그래서 아래 순서로 공부하면 이론 따로, 실전 따로가 아니라 바로 프로젝트 산출물이 나옵니다 🎀

## 🗺️ 로드맵

- [ ] 01. 디자인 시스템 기초 — 색상 팔레트, 타이포그래피 스케일, 여백(spacing) 규칙 정하는 법
- [ ] 02. Figma 기본기 — 프레임, 오토레이아웃, 컴포넌트/베리언트, 텍스트 스타일 등록
- [ ] 03. 정보 구조(IA)와 네비게이션 — 마이페이지·관리자 화면처럼 "여러 항목을 보여주는 화면" 설계법
- [ ] 04. 와이어프레임 → 목업 흐름 — Lo-fi(뼈대)부터 Hi-fi(실제 색/폰트 입힌 것)까지
- [ ] 05. 폼(Form) UX — 로그인, 일정 편집처럼 입력이 있는 화면 설계 원칙
- [ ] 06. 지도+채팅 화면 UX 패턴 — 스팟 검색 화면(대화창+지도+트레이) 참고 사례와 레이아웃 원칙
- [ ] 07. 사용성 휴리스틱(Nielsen 10) — 팀 회의에서 디자인 근거를 설명할 때 쓰는 체크리스트
- [ ] 08. 실전: 마이페이지/관리자 화면 목업 제작 — 01~07 적용해서 실제로 만들기
